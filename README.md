##  Project Overview

Ndlovu Poultry Farm is a rural poultry business website developed to introduce the farm to potential customers and provide information about its poultry products.

The website aims to improve the farm's online presence and make it easier for customers to discover the products it offers. It provides an accessible way for customers to learn about the business, explore its products, and find contact information.

The website was developed using HTML to structure the pages and CSS to style the website and create a consistent visual appearance.

 Website Goals and Objectives

Primary Goal: To establish an online presence for Ndlovu Poultry Farm and make information about its poultry products accessible to customers.

  Objective 1:Present clear information about the poultry farm and its products.

  Objective 2: Provide a user-friendly website that allows visitors to navigate between the available pages.

  Objective 3:Use CSS styling to create a visually consistent and readable website.

  Objective 4: Make it easier for potential customers to find information about the farm and contact the business.



# Key Features and Functionality

Homepage: Introduces Ndlovu Poultry Farm and provides visitors with an entry point to the website.

  About Us: Provides information about the poultry farm and its business.

  Products: Displays information about the poultry products offered by the farm.

  Contact Information: Helps visitors find ways to contact the business.

  CSS Styling: Adds colours, styling, and visual consistency to the website.
